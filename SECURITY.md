# Security Policy

## Reporting a Vulnerability

ConnectMasjid takes the security of our platform and user data seriously. If you discover a security vulnerability in this MCP server or our platform APIs, please report it responsibly.

### How to Report

Please **do not** open public GitHub issues for security vulnerabilities. Instead, report them via email to:

- **Security Email**: support@connectmazjid.com

Please include:
- A description of the vulnerability and its potential impact.
- Detailed reproduction steps or proof-of-concept.
- Any suggested remediations or mitigations.

### Responsible Disclosure

We ask that you give us reasonable time to investigate and address the issue before making any information public.
